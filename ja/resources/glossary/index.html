プロダクト用語集

接続された運用モデルのための共通言語。

これらの定義は製品、技術的な、監査会話を整合させます。advanexus オブジェクトを説明するもので、外部の規制上の／ベンダー用語を再定義しません。

プラットフォームを見る →

01

スコープと識別情報

Tenant は組織／データ分離境界です。Project は Tenant 内のメンバーシップ／実行スコープです。Actor はアクションに関連付けられた既知のユーザー、サービス、制御されたシステム識別情報です。

セッションレジストリ（セッション登録簿）

認証済みの JTI、Actor、Tenant、有効な Project、有効期間、失効状態を検証するサーバー管理の記録。

権限スコープ（権限範囲）

サーバー側の解決後に現在の Actor が利用できる有効な操作／Project。

02

データとバージョン

Source は制御された接続識別情報、Dataset は安定したガバナンスされたデータ契約です。Version は対応済みのファイル、テーブル、Dataset、Report、Notebook、その他バージョン管理されたオブジェクトの不変の状態です。

FileVersion と TableVersion

それぞれ不変の Source ファイル識別情報と不変の管理された物理テーブル公開を表します。

DatasetVersion

不変の Dataset 管理の SQL/スキーマ/列契約。仮想のバージョンは必ずしも稼働中の行を固定しません。

ReportVersion

後続の AnalyticsRun のために受け入れ済みのされた不変の分析上の意図／正確な DatasetVersion バインディング。

03

実行と結果

Run は 1 回の具体的な実行試行／結果です。Artifact は実行に関連する制限された保持された出力です。実行時フィルターは実行コンテキストを変更し、サーバー管理の RLS はデータ可視性を強制します。

QueryExecution

Source、SQL、成功／失敗コンテキストを持つ 1 回の SQL Console サービス実行試行。

AnalyticsRun

対象バージョンバインディング、フィルター、権限/RLS、診断情報、成果物コンテキストを持つ 1 回の Report 実行。

CellRun

Notebook リビジョン、環境、カーネル生成に紐付けられたされた 1 回の ANpy コードセル実行。

04

証拠と調査

Evidence はカノニカルな Source が裏付けられる Actor、スコープ、変更、コンテキスト、結果です。Finding は確認を要する対応済みの条件です。Case は Source イベントを変更せず人による調査を整理します。

Evidence Package

スコープ、マニフェスト、チェックサムメタデータを持つ権限確認済みの制限された技術的なエクスポート。自動のデジタルの署名／法的な結論ではありません。

Service Desk Ticket（サポート票）

Project が認可条件式ではなく任意のコンテキストになり得る Tenant 全体の運用上の連絡記録。

05

Assurance と整合性

Assurance は権限を考慮した読み取り／調査レイヤーです。プロジェクションは再構築可能な正規化されたビューです。Integrity は検証強度を表し、再現可能性は説明のない信頼度スコアではなく明示的な基準を評価します。

カノニカルな Source（正式な情報源）

対応済みのワークフローが使用する正式な記録を所有するモジュール。

プロジェクション

対応済みのカノニカルイベント、スナップショット、過去のアダプターから構築される再構築可能な Assurance 読み取りモデル。

Intelligence Turn と Action

Turn は応答で完了する場合があります。Action は確認／承認契約の下で提案済みの／実行済みの登録済みの副作用を記録します。

簡潔に知る

advanexus とは何ですか？

advanexus は、対応するシステム、データフロー、自動化、登録済み AI 支援アクションを横断する、企業の重要実行のためのコントロールと証拠のシステムです。コンテキスト、ルール、権限、実行、成果、復旧、利用可能な証拠を、スコープの明確な一つの運用モデルで接続します。

成果を後から再現し、説明できますか？

advanexus は能力が対応する範囲で正確な契約と実行コンテキストを保持し、明示的な再現可能性基準を評価します。万能な再実行を約束せず、再現可能、部分的に再現可能、再現不可能、未評価のいずれかを報告します。

つながりを保ったまま、前へ。

advanexus は advance と nexus の融合。データ、意思決定、説明責任、証拠のつながりを切らずに前へ進むことを表します。
