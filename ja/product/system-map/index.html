    ビジネスストーリーを再生

    01 / 01
    マップは裏付けられた事実と証拠を示しますが、業務上の義務、承認、最終判断は人が担います。 メタデータ、プレビュー、クエリ、転送、書込み、削除、品質の能力は、コネクター、ドライバー、承認済み展開によって異なります。 安定 ID や変更可能な定義は実行ではありません。明示的なバージョン参照が承認済みの意図を保持します。 クエリは操作または変更可能な作業定義であり、管理された Dataset ID ではありません。 定義とバージョンは実行を証明しません。各 Run は固有のスコープ、状態、結果を持つ別記録です。 将来のスケジュール発生時には新たな受け入れチェックを実行し、ディスパッチ前にその時点の不変 JobVersion を永続的な PipelineRun に固定します。ビジネス効果の exactly-once とロールバックは、実行エンジン、コネクター、ポリシー、実証済みの冪等性に依存します。 QualityRule は現在、変更可能なソース契約であり、DatasetVersion に固定された不変ルールではありません。QualityRun は PipelineRun と別記録です。 DatasetVersion は契約、SQL、スキーマ、関係をロックしますが、物理ソース行は固定しません。行の再現には保持結果、成果物、または具体化 snapshot が必要です。 下書きは実行不可です。ReportVersion は DatasetVersion または不変 SQL snapshot に固定でき、実行時フィルターは AnalyticsRun に属します。 VisualizationDraft は、ユーザーが所有する単一の有界 QueryExecution スナップショットの一時ビューであり、SQL を再実行しません。保存すると正規の Dataset と Report のバージョンが作成されますが、ドラフト自体は権威ある記録にはなりません。 Visualization は結果を人が理解するためのビューであり、データソースでも結果の正しさの証拠でもありません。 公開済み VisualizationWorkspaceVersion は、レスポンシブレイアウトと正確な ReportVersion／DatasetVersion の関連付けを固定します。DashboardRun → WidgetRun → ユーザーに見える AnalyticsRun は、部分成功を含む各結果を保持します。更新スケジュール、準備済みデータ、アラート、統制された共有は、個別にバージョン固定され再認可される制御であり、共有とエクスポートは引き続きデプロイ方針で制限されます。 Assurance は正規ソース上の権限考慮型読み取りモデルです。ソースの実行履歴を所有、改変、暗黙補完しません。 Service Desk Ticket は運用サポートのワークフローであり、Assurance Case でも是正成功の証拠でもありません。 EvidencePackage はマニフェストとチェックサムを含む技術エクスポートであり、自動的なデジタル署名、WORM、法的最終記録ではありません。 Intelligence 提案は、正規サービスが実行する前に、決定論的検証、人またはポリシーの確認、最新の認可を必要とします。 Tenant、Project、Actor、メンバーシップ、権限、RLS は各操作で再確認されます。役割ビューは認可システムではありません。 監査と Outbox の投影は結果整合の読み取り側証拠です。正規サービス状態が権威を持ち、証拠の欠落は可視のままです。
