Integrationer

Forbind heterogene systemer gennem eksplicitte kapabilitetskontrakter.

Navnet på en forbindelse er kun begyndelsen. advanexus fastlægger, hvilke registrerings-, læse-, overførsels-, skrive-, kvalitets- og analyseoperationer den konkrete driver og implementering sikkert kan understøtte.

Drøft jeres kildelandskab →

01

Sytten forbindelseskontrakter i otte kapabilitetsfamilier – uden falsk paritet.

Kataloget omfatter PostgreSQL, kompatibilitet med MySQL og MariaDB, Microsoft SQL Server, Oracle, IBM Db2, SQLite, SAP HANA, Snowflake, Databricks SQL, DynamoDB, MongoDB, Redis, Cassandra, Neo4j, Elasticsearch, OpenSearch og Salesforce.

02

Kapabiliteten afgør, hvad grænsefladen kan tilbyde.

Relationelle, dokument-, nøgle-værdi-, bredkolonne-, søge-, graf- og SaaS-systemer deler ikke én naturlig forespørgselsmodel. Grænsefladen må kun tilbyde metadata-, forhåndsvisnings-, forespørgsels-, overførsels-, sletnings- eller kvalitetsadfærd, som den aktuelle Source-kontrakt eksponerer.

03

En forbindelse er en miljøbeslutning.

Leverandørklienter, netværksstier, TLS, legitimationsoplysninger, privilegier, API-grænser og målpolitikker verificeres under implementeringen. Offentlig visning af en forbindelse certificerer ikke alle leverandørversioner.

04

Styret Analytics har en smallere direkte sti.

Den aktuelle Dataset-bevidste Analytics-compiler er målrettet PostgreSQL. Andre forbindelser kan deltage gennem en godkendt materialiserings- eller dialektadaptersti; katalogplacering alene giver ikke direkte compilerunderstøttelse.

05

Én styringsvej på tværs af et blandet virksomhedslandskab.

advanexus fungerer med understøttede relationelle teknologier, datawarehouses, key-value-, dokument-, søge-, graf- og enterprise-SaaS-teknologier.

Hver forbindelse udstiller kun de handlinger, som dens accepterede connector, driver, politik og implementering kan udføre sikkert.

  • 01Kerneforretnings- og ERP-data — PostgreSQL, MySQL, MariaDB, SQL Server, Oracle, Db2 og SAP HANA
  • 02Datawarehouses og lakehouses — Snowflake og Databricks SQL
  • 03Operationelle key-value-systemer — DynamoDB og Redis
  • 04Dokument- og wide-column-datalagre — MongoDB og Cassandra
  • 05Søge- og genfindingsplatforme — Elasticsearch og OpenSearch
  • 06Graf og Enterprise SaaS — Neo4j og Salesforce
