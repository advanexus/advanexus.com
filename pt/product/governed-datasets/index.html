Datasets governados

Transforme definições de dados em ativos versionados com linhagem explícita.

O Dataset separa o SQL exploratório de um contrato de dados reutilizável. A identidade estável, as versões imutáveis e os metadados semânticos criam uma base controlada para reporting sem ocultar a linhagem da origem.

Ver a analítica controlada →

01

Um Dataset é um contrato, não um resultado de consulta com outro nome.

O Dataset liga origem e linhagem da consulta, SQL normalizado, colunas e metadados semânticos, estado do ciclo de vida e DatasetVersion imutáveis. SavedQuery mantém SQL editável; o relatório descreve a intenção analítica.

01Um Dataset pode ter origem numa execução da Consola SQL, numa SavedQuery, numa tabela física ou numa transformação controlada.

02DatasetColumn regista o esquema conhecido e os metadados de perfil da versão exata.

03A promoção a partir da Consola SQL alinha o Dataset canónico com a projeção semântica do Analytics sem fundir as respetivas responsabilidades.

02

Versão significa estado do contrato exato.

Alterar o SQL, as junções, a Source, o esquema, as colunas ou os metadados de coluna controlados pelo Dataset cria um novo DatasetVersion. Métricas analíticas, RLS e permissões do relatório continuam a ser contratos distintos. Os relatórios existentes permanecem fixos até o utilizador validar o novo DatasetVersion e guardar um novo ReportVersion.

Report v4 → Dataset v2 · Report v5 → Dataset v2 · Report v6 → Dataset v3

03

Uma versão virtual não congela automaticamente as linhas.

Quando um DatasetVersion guarda um contrato SQL ativo, execuções posteriores podem ler linhas mais recentes da origem com a mesma definição. A reconstrução exata de um resultado histórico exige o hash da execução e um artefacto retido, ou um instantâneo materializado explícito.

04

A comparação mostra a alteração registada, não um impacto inventado.

Os utilizadores podem comparar SQL normalizado, colunas, tipos e metadados de linhagem conhecidos. A plataforma não reivindica uma análise universal do impacto empresarial a jusante para relações que nunca foram registadas.

01Identidade exata das versões à esquerda e à direita e SHA-256 do contrato SQL

02Comparação SQL com inserções e remoções

03Coluna, tipo, alterações de metadados anuláveis e conhecidas

04Estados explícitos de inalterado, alterado, adicionado, removido e indisponível

05

O Dataset e o Analytics mantêm responsabilidades separadas.

O Dataset controla o ativo e as suas versões de dados estáveis. O Analytics controla métricas, RLS, permissões de recursos, Query Context e execução de relatórios. Esta distinção mantém verificáveis os limites de governação.

06

A evolução é uma decisão de aceitação explícita.

Um novo DatasetVersion não move silenciosamente os relatórios existentes. O utilizador compara o contrato, valida dimensões e métricas, pré-visualiza a consulta gerada e guarda depois um novo ReportVersion ligado ao DatasetVersion aceite. ReportVersion anteriores e as respetivas execuções mantêm as ligações originais.

  1. 01

    Compare Dataset v2 com v3.

  2. 02

    Confirme a SQL, colunas e tipos alterados.

  3. 03

    Abra o rascunho do relatório contra o Dataset v3.

  4. 04

    Valide os metadados e compile SQL só de leitura.

  5. 05

    Pré-visualização sob permissão atual e contexto RLS.

  6. 06

    Guardar Report v6 → Dataset v3 apenas após a aceitação.

Páginas relacionadas

Analítica controlada Fixe o contrato de dados. Governe a execução. Explique o resultado.

A analítica controlada liga um relatório a DatasetVersion exatos, valida o Query Context no servidor e conserva as permissões, o RLS, os filtros, as ligações e o contexto dos artefactos subjacentes a um resultado suportado.

→ Qualidade dos dados Torne a qualidade parte da execução, não um documento posterior.

O Data Quality transforma expectativas orientadas para a origem em asserções SQL repetíveis, com uma condição de aprovação clara, QualityRun persistente e evidência de falha delimitada.

→ Entrega de analítica governada Explique por que um resultado mudou.

Definições e versões de entrada diferentes podem gerar relatórios contraditórios para a mesma pergunta.
