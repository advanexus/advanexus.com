    01 / 01
    地图可以呈现有支撑的事实与证据；业务义务、审批和最终决策仍由人负责。 元数据、预览、查询、传输、写入、删除与质量能力会随连接器、驱动和已接受部署而变化。 稳定身份或可变定义并不等于一次运行；明确的版本引用保存已接受意图。 查询是一项操作或可变工作定义，不是受治理的 Dataset 身份。 定义和版本不能证明已执行；每次运行都是拥有自身范围、状态与结果的独立记录。 未来一次计划触发会执行新的准入检查，并在分派前将当时最新且不可变的 JobVersion 固定到持久化的 PipelineRun 中；业务效果的严格一次语义与回滚取决于执行器、连接器、策略以及经证实的幂等性。 QualityRule 当前是可变的数据源契约，而非固定到 DatasetVersion 的不可变规则；QualityRun 与 PipelineRun 仍分开。 DatasetVersion 锁定契约、SQL、模式与关系，而非物理源行；行级复现需要保留结果、制品或明确的物化快照。 草稿不可执行。ReportVersion 可固定到 DatasetVersion 或不可变 SQL 快照；运行时筛选器属于 AnalyticsRun。 VisualizationDraft 是由用户拥有的临时视图，仅对应一个有界 QueryExecution 快照，不会重新执行 SQL。保存会创建规范的 Dataset 和 Report 版本；草稿本身仍不是权威记录。 可视化是帮助人理解结果的视角，不是数据源，也不是结果正确的证明。 已发布的 VisualizationWorkspaceVersion 会锁定响应式布局以及精确的 ReportVersion 和 DatasetVersion 绑定。DashboardRun → WidgetRun → 用户可见的 AnalyticsRun 会保留每个结果，包括部分成功。刷新计划、预准备数据、告警和受控共享是彼此独立、绑定版本并重新授权的控制；共享和导出仍受部署策略约束。 Assurance 是建立在规范来源之上的权限感知读取模型；它不拥有、改写或静默补全源执行历史。 Service Desk 工单是运营支持流程，不是 Assurance Case，也不能证明整改成功。 EvidencePackage 是含清单和校验和元数据的技术导出；它不会自动成为数字签名、WORM 或法律终局记录。 Intelligence 提案必须通过确定性验证、人工或策略确认以及最新授权，规范服务才能执行操作。 每项操作都会重新检查 Tenant、Project、Actor、成员关系、权限与 RLS；角色视角不是授权系统。 审计与 Outbox 投影是最终一致的读取侧证据；规范服务状态仍具权威性，缺失证据保持可见。
