01

范围与身份

Tenant 是组织与数据隔离边界。Project 是租户内的成员关系与执行范围。Actor 是与操作关联的已知用户、服务或受控系统身份。

会话注册表

由服务器拥有的记录，用于验证已认证 JTI、Actor、Tenant、当前 Project、有效期与撤销状态。

权限范围

经服务器解析后，当前 Actor 可以使用的有效操作与项目。

02

数据与版本

Source 是受控连接身份。Dataset 是稳定的受治理数据契约。Version 是受支持文件、表、Dataset、Report、笔记本或其他版本化对象的不可变状态。

FileVersion 与 TableVersion

分别表示不可变的源文件身份和不可变的托管物理表发布。

DatasetVersion

Dataset 拥有的不可变 SQL、架构与列契约；虚拟版本不一定冻结实时数据行。

ReportVersion

为后续 AnalyticsRun 接受的不可变分析意图与准确 DatasetVersion 绑定。

03

执行与结果

Run 是一次具体执行尝试及其结果。Artifact 是与运行关联、受限且保留的输出。运行时筛选器改变执行上下文；服务器拥有的 RLS 强制执行数据可见性。

QueryExecution

一次 SQL Console 服务执行尝试，包含 Source、SQL 以及成功或失败上下文。

AnalyticsRun

一次报告执行，包含准确版本绑定、筛选器、权限/RLS、诊断和制品上下文。

CellRun

一次 ANpy 代码单元执行，绑定到笔记本修订、环境和内核代次。

04

证据与调查

Evidence 是权威来源能够支持的 Actor、范围、变更、上下文与结果。Finding 是需要审阅的受支持状况。Case 组织人工调查，但不改变源事件。

Evidence Package

经过权限检查的有限技术导出，包含范围、清单和校验和元数据；并非自动数字签名，也不具有法律终局性。

Service Desk 工单

租户级运营沟通记录，其中 Project 可以是可选上下文，而非其授权谓词。

05

Assurance 与完整性

Assurance 是感知权限的读取与调查层。Projection 是其可重建的规范化视图。Integrity 描述验证强度；Reproducibility 评估明确标准，而不是无法解释的置信分数。

权威来源

拥有受支持工作流所使用权威记录的模块。

投影

由受支持的权威事件、快照和历史适配器构建的可重建 Assurance 读取模型。

Intelligence Turn 与 Action

Turn 可以在给出响应后完成；Action 依据其确认与审批契约记录已提议或已执行的注册副作用。

简明解答

什么是 advanexus？

advanexus 是贯穿受支持系统、数据流、自动化与已登记 AI 辅助操作的关键企业执行控制与证据系统。它在一个范围明确的运行模型中连接上下文、规则、授权、执行、结果、恢复与可用证据。

结果能否在以后复现并解释？

在能力支持的范围内，advanexus 保留精确契约与执行上下文，并评估明确的可复现标准。它报告可复现、部分可复现、不可复现或未评估，而不是承诺通用重放。

保持连接，持续向前。

advanexus 融合 advance 与 nexus：向前迈进，同时不断开数据、决策、责任与证据之间的连接。
